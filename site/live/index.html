      Helper agents

      When a phase has several pieces of work, Claude splits it into tasks and gives each to the cheapest helper that can do it well: simple lookups and tiny edits to Haiku at low effort, ordinary coding to Sonnet, harder coding to Sonnet at high effort, hard-to-undo decisions and risky code to Opus. Tasks in the same wave run at the same time; a task that fails moves up one level.
