# Incident process
**Declare:** write the time and a one-line description in a shared note the moment something user-visible is wrong or data may be exposed.
**Communicate:** post a short status (what is affected, what you know, next update time) wherever users look (a status page does not exist yet: create one before launch). Update at the time you promised, even if nothing changed.
**After:** within 3 days write a blameless review: timeline, impact, root cause, what detected it, what would have detected it sooner, actions with owners.
**Template:** Summary - Impact (who, how long) - Timeline - Root cause - Detection - What went well / badly - Actions.
**Privacy:** if personal data may have been exposed, check the legal notification duty for the users' region (undecided for v1).
